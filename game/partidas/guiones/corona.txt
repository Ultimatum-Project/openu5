# el pasadizo del clavicémbalo en (17,13) —justo al norte—, una puerta mágica en (15,19)
# y una escalera (K)limb en (15,15). Rumbos MEDIDOS desde (17,14): N 0 · S 3 · E 0 · O 3.

# el N 0 de los rituales: en (17,13) hay el tile 0x4F del PASADIZO, que no se pisa — se
# abre con la melodía, y sólo si el clavicémbalo está inmediatamente al sur de una celda

# las separa, y quien mire sólo el número las unificará.
