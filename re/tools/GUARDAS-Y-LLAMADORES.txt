# Este fichero es la MISMA forma sobre las poblaciones restantes.

# QUÉ ES «LLAMADOR» AQUÍ: el sitio que la EJECUTA, no el que la nombra. Un docstring, una
# línea de prosa o un comentario que diga «esto lo vigila X» NO son llamadores — es
# exactamente el error que costó las cinco instancias. Se escribe el fichero:línea del
# `subprocess.run` / `node` / `python3` / `import` que la corre.
#
# 🔴 SE INSERTA, NO SE REESCRIBE (misma advertencia que FUERA-DE-PUERTA.txt): es un fichero
# COMPARTIDO. El control es el diff: cero borrados.
#
# Formato:  <RUTA desde la raíz>  # <llamador con fichero:línea, o razón de no tenerlo>
# 🔴 RUTA, no nombre pelado — al revés que FUERA-DE-PUERTA.txt, porque esta población cruza
